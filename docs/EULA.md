# Tether 最终用户许可协议（草案）

> 状态：草案，需法务复核后对外使用。当前仅用于内部评审，不构成正式法律文本。

## 1. 许可范围

Tether 由 APP、DSH 插件、Node 和 Hub 服务组成。在遵守本协议的前提下，授权你在自有设备和自有 Hub 上安装、运行和内部评估 Tether，用于连接你拥有或获授权管理的设备。

## 2. 限制

- 不得将 Tether 用于未经授权访问他人设备、绕过访问控制或规避审计。
- 不得移除版权与许可声明，不得将第三方组件按本协议重新授权。
- DSH、第三方 DSH 插件及其更新由各自权利人提供，Tether 不为其行为、兼容性或数据负责。

## 3. 数据与备份

你负责配置、设备凭据和传输数据的备份与权限。更新和修复前 Tether 会尽量备份 profile 等关键文件，但不构成数据恢复保证。

## 4. 无担保与责任限制

在适用法律允许的最大范围内，Tether 按“现状”提供，不承诺无中断或无错误。因使用或无法使用本软件造成的间接损失，Tether 不承担责任。具体责任上限以正式商业合同为准。

## 5. 终止

违反本协议或用于未授权访问时，许可自动终止；你应停止使用并删除相关副本。开源/第三方组件的许可在其各自条款下继续有效。

## 6. 适用法律
