# Tether 隐私说明（草案）

> 状态：草案，需法务复核后对外使用。当前仅用于内部评审。

## 本地保存

- APP 设置、登录会话、设备身份、surface 缓存和日志保存在 Tether 的数据目录。
- Node 保存设备令牌、运行记录、审计记录和传输临时文件。
- DSH 的会话、插件和配置保存在 DSH 自己的 home/profile，不归 Tether 管理。

## 上传到 Hub

- 账号信息（邮箱、昵称、头像）和设备元数据（设备 ID、平台、版本、在线状态）。
- 设备间的文件内容、DSH surface 资源和操作请求会经 Hub 中转；Hub 仅在转发所需范围内处理，不用于广告或画像。
- 不接入第三方统计、广告或外部追踪脚本。

## 日志与凭据

- 日志用于排障，可能包含本机路径和错误信息；不要放入公开仓库。
- Hub 访问令牌、Node 令牌和 DSH 凭据只保存在受限文件/环境变量中，不写入发布包。

## 用户控制

- 可在设置中退出账号、修改昵称/头像/密码；设备可在 Hub 侧移除。
- 本地数据由用户自行删除；删除前建议备份 DSH profile 和 Tether 数据目录。
- DSH 本体及第三方 DSH 插件的数据实践由各自提供方负责，不在本说明覆盖范围。

## 保留与安全

- Hub 保存账号/设备记录和必要审计，保留期限按运营策略与法律要求执行。
- 传输使用 HTTPS/WSS；部署方负责服务器密钥、证书、备份和访问控制。
