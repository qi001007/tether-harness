# 核心产品恢复与验收计划

更新日期：2026-10-28。本计划描述公开客户端的产品门禁，不记录本机账号、会话、凭据或服务器部署细节。任何未通过的门禁都不能表述为整套产品已验收。

## 产品约束

1. APP、DSH 插件和目标 Node 是独立组件；分别发布的用户制品与完整仓库源码开发路径分开说明。
2. 同一设备上的 APP 和插件连接同一个 DSH Host 与会话。Host 是模型执行和会话写入的唯一权威；Tether 服务负责认证、路由与状态同步。
3. 设备身份与后台实例身份分开；并存实例必须有明确所有权，防止设备身份抢占、重复写入和过期事件污染。
4. 更新流程核对组件与协议兼容性、制品完整性，先暂存后切换；任务运行时不自动重启，并保留用户数据与凭据。数字签名、任意启动崩溃恢复及完整远端更新仍须单独验收。

## 发布前门禁

2026-10-28 推进顺序：真实 Electron 渲染和异常响应检查已通过；`v0.2.1` 基础版本 APP、插件、Node ZIP 与统一清单已发布。官方 HTTPS 下载和 SHA-256、APP/Node 官方清单检查及插件离线预检已通过；尚未实际安装或升级。旧版用户需先手动安装一次具备更新能力的基线，再以后一版本验证软件内升级。服务器更新接口、目标节点升级、双机业务及完整失败恢复仍单独验收。
