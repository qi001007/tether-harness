# 计划：Tether APP 桌面壳、统一图标与托盘

状态：**已完成**（2026-11-03，v0.2.73 已发布）

## 目标

1. APP 不再显示 Electron 原生标题栏，改成 DSH 风格的一体化顶栏；保留现有功能图标。
2. 用登录页的网络视觉重做产品图标；桌面、任务栏、悬停缩略图、Windows 托盘同一套图标。
3. 关闭窗口默认隐藏到托盘；托盘可重新打开或真正退出。

## 步骤与验收

### 1. 图标源与产物
- 以最初版图标（深海军蓝底、白环、橙环）为母版，仅把中间连接线改成 V1 立 S，做 1024×1024 PNG 源。
- 生成多尺寸 `assets/tether-app-s.ico`（16/24/32/48/64/128/256）与 `assets/tether-app-s.png`；`assets/tether-app-s.svg` 保留同构矢量源。
- 验收：16×16、32×32、256×256 都能辨认是一个网络连接标记；四类图标逐字节同源（同一 ico/png）。

### 2. 无原生标题栏的 APP 壳
- `BrowserWindow` 改为无边框（`frame: false`），去掉系统标题栏；顶栏高度约 40px，整条可拖动。
- 顶栏右侧加入自绘窗口控制：最小化、最大化/还原、关闭；按钮 `-webkit-app-region: no-drag`，其余区域 `drag`。
- 关闭按钮走托盘隐藏，不直接退出；最大化状态切换图标与窗口状态同步。
- 验收：窗口顶部没有第二层原生标题栏；DSH 页面从窗口顶部开始；拖动、最大化、还原、最小化、关闭都正常。

### 3. 托盘
- 主进程创建 `Tray`，图标使用统一 ico；右键菜单：打开 Tether / 退出 Tether。
- 点击关闭按钮隐藏窗口到托盘；再次点击托盘或菜单“打开”恢复并聚焦。
- `window-all-closed` 在托盘存在时不退出；只有菜单“退出”或更新重启才真正 `app.quit()`。
- 第二实例启动时恢复已有窗口。
- 验收：关闭后进程仍在、任务栏窗口消失、托盘图标存在；点击托盘恢复；退出后进程结束。

### 4. 快捷方式与安装脚本
- `desktop/install-app.ps1` 继续使用 `assets/tether-app-s.ico`；本机桌面/开始菜单快捷方式的 `IconLocation` 更新到新 ico。
- 验收：桌面、开始菜单、任务栏、Alt+Tab 悬停、托盘五处视觉一致。

### 5. 门禁与发布
- 新增/更新测试：窗口无边框、托盘创建、关闭隐藏、IPC 窗口控制、图标文件存在且多尺寸。
- 跑 mjs/cjs/pytest、`build.mjs --check`、`build-web.mjs --check`、`validate_versions()`。
- 版本升到 0.2.73，发布并更新 DESKTOP；LAPTOP 只做兼容性更新，不在这轮处理 DSH 升级问题。

## 边界

- 不改 DSH 插件加载机制；本轮只改 Electron 壳、图标、托盘。
- 不使用全局依赖修改；顶栏是 Tether APP 自己的 chrome。
- 托盘“退出”必须真正结束 Node/supervisor，不能留下后台孤儿进程。
