# Tether 专项产品与融合规范（项目专有规则）

> **分工说明**：通用的跨项目前端 UI/UX 与 13 条视觉交互准则统一由全局 Skill `owner-ui-design` 承载（Antigravity / Codex / Qoder 三端按需加载）。本文件**仅记录 Tether 项目特有的产品边界、系统融合与前后端协同规范**，与 `owner-ui-design` 叠加执行。

---

## 1. 启动首屏与主导航

- **默认首屏为 DSH（左侧第 1 个图标）**：全新启动 APP 后必须默认进入左侧第 1 个图标对应的 DSH 工作台，不得默认进入多 Agent / Codeg 页面。
- **状态与错误提示明确分级**：`notice` / `updateToast` 显式区分 `success` / `info` / `warning` / `error`，禁止通过中文关键词猜颜色；冷启动 OAuth 与设备未就绪期间处于加载态，不得因提前并发探测而闪现假红错条。

## 2. Codeg 深度内化与「新建任务」旧欢迎页彻底移除

- **彻底删除原 Codeg 新建对话欢迎页**：从源码与路由底层删除 Codeg 原生「新建任务」欢迎页（`WelcomeHero`、`QuickActions` 技能宣传栏、`WelcomeTip`、`forceAgentSelection` 兜底欢迎枝及自动创建无意义空白草稿的路由链路）。
- **智能体页（`TetherAgentPage`）全权替代入口**：
  - 所有对话标签关闭后（不仅是首次进入），以及侧边栏「智能体」入口、左下角快捷入口，统一回到我们自己的 **`TetherAgentPage`（智能体页面）**。
  - 在 `TetherAgentPage` 内直接呈现左选项目 + 右选 Agent + 点击「结构化」直进可用对话，不再绕道原欢迎页。
  - 从原界面筛选出真正有工程价值的模式选项（**常规** / **方案规划** / **系统排错** / **并行子代理**），直接集成在 `TetherAgentPage` 的轻量启动条中供按需切换。
  - 同步清理前端与后端无用死代码（如原 `Web 服务` 引导、冗余欢迎配置状态及旧临时桥）。
- **直连目标设备原生 `dsh --profile acp`**：多 Agent 对话直连目标设备侧 `dsh --profile acp`（支持模型选择、附件、流式输出、会话恢复与锁定 DSH 会话交接），彻底淘汰依赖 `window.parent === window` 的 postMessage `dsh-bridge`。

## 3. 目标设备资源管理器与文件编辑边界

- **100% 走内置目标设备资源管理器**：DSH 与多 Agent 页面中所有「创建/打开项目」「选择文件夹」「上传/附带文件」必须调用 Tether 内置目标设备资源管理器，**严禁弹出本机 OS 原生文件对话框**。
- **内置目录同步与键鼠效率**：支持窗口获焦/可见自动刷新 + 目标侧轻量目录监听 + 键盘快捷键（`↑↓` / `Enter` / `F2` / `F5` / `Delete`），刷新时保留滚动位置、选中项与未保存草稿；级联右键菜单遵循预测三角区防误关。
- **内置终端与全格式查看/编辑定位**：
  - **终端**：任意目标目录打开多种 Shell。
  - **代码/文本**：Monaco 级编辑能力。
  - **Word / PPT / PDF**：高保真只读预览（避免复杂富文本排版破坏与格式地狱）。
  - **Excel（`.xlsx`）轻量实用型电子表格编辑器**：拒绝单格死改，亦不堆叠完整桌面 Office；须具备**多选与复制粘贴、撤销重做、拖拽填充柄、常用公式与实时重算（`SUM`/`AVERAGE`/`COUNT`/`MIN`/`MAX`/`IF`/四则运算）、一键快速求和与底栏选中区实时统计、行列增删、排序筛选、多 Sheet 切换，以及干净写回 `.xlsx`**（仅对含宏/复杂图表的特殊工作簿给出保护提示）。

## 4. 网络画布、设置架构与非阻塞悬浮窗

- **网络画布只留直接操作**：拖节点改布局、拖端口连线、点选边高亮后在轻工具条/右键/Delete 断开；右键菜单只检查节点，不强行切换全局当前设备；移除 `全部/我的` 筛选、OS 图例，以及画布内的 `连接管理` / `自动中转` 入口。
- **8 大分组设置架构（带作用域标签）**：`常规与外观`、`工作区与智能体`、`连接与网络`（收纳连接列表与自动中转）、`权限与共享`、`设备与 DSH`、`更新`、`账号`、`关于`；卸载、撤销信任与清除设备身份隔离至独立危险区。
- **宿主持久化与可拖拽非阻塞浮窗**：传输队列、`AbortController` 与长耗时任务全部提升至主宿主持久化；设置、资源管理器、传输列表、设备详情均改为非阻塞、可拖拽标题栏的多浮窗（关窗不断流），仅目录选择器、OAuth 登录和危险二次确认保留强焦点模态。

## 5. 跨节点小版本兼容

- 稳定基线建立后，跨节点微小版本差异（如 `0.5.x` 与 `0.5.y`）不得整条链路崩溃；接口缺省字段或未升级能力须做优雅降级并给出清晰状态指示。
