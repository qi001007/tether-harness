# Tether 统一前端设计与产品交互规范（Antigravity × Codex 共用唯一真相）

> **定位**：本文档是 **Antigravity 与 Codex** 在本项目中唯一共用的前端 UI/UX 与交互设计宪法。任何界面重构、组件新增、Codeg 深度融合或视觉审查，开工前必须先核对本文件，违背条文一律视为缺陷。

---

## 一、Tether 产品与融合六大铁律

1. **极简文字 · 图标优先**：尽量少写解释性长句、副标题和弹窗说明文案，优先用高精度图标 + 简短 2–4 字标签 / 数字指标表达状态与操作；非必要引导横幅（Welcome Tip / 教学角标）全部移除。
2. **默认首屏为 DSH（左侧第 1 个图标）**：全新启动 APP 后必须默认落到左侧第 1 个图标对应的 DSH 工作台，不得默认跳入多 Agent / Codeg 页面。
3. **Codeg 深度内化融合（非套壳 / 非临时桥）**：
   - 将选定版本的 Codeg 彻底改造为 Tether 内部统一风格模块，字体、配色、圆角、控件、导航与侧边栏（如与「自动化」「待办任务」平级的「智能体」入口及左下角快捷入口）必须与 Tether 宿主完全统一。
   - 多 Agent 对话直连目标设备原生 `dsh --profile acp`（支持模型选择、附件、流式输出、会话恢复），淘汰 `window.parent === window` 的脆弱 postMessage `dsh-bridge`。
   - 清除无用的原生引导页/自动弹出「新建任务」弹窗及冗余技能宣传卡片；新增流程性功能前须向主人汇报「1. 怎么加；2. 用户何时/如何用；3. 是否成体系」。
4. **目标设备资源管理器 100% 接管选目录与传附件**：
   - DSH 与多 Agent 页面中所有「创建/打开项目」「选择文件夹」「上传/附带文件」均必须调用 Tether 内置的**目标设备资源管理器**，**严禁弹出本机 OS 原生文件对话框**。
   - 目标设备文件能力定位：内置终端（支持任意目录/多种 Shell）+ Monaco 级文本编辑；PDF/PPT/Word 只读预览（不堆复杂富文本格式编辑）；`.xlsx` 表格受限单元格编辑（仅修改静态数据格并原子保存，含宏/绘图的工作簿保持只读）。
   - Explorer 必须支持实时/准实时目录同步（窗口获焦/可见刷新 + 轻量目录监听 + `↑↓`/Enter/F2/F5/Delete 快捷键，刷新时保留滚动、选中与未保存草稿）。
5. **非阻塞可拖拽悬浮窗与宿主持久化任务**：
   - 文件上传/下载、Agent 会话、终端与长耗时操作的状态和 `AbortController` 必须提升到**主宿主（App Shell）持久存活**，关闭弹窗或切换页面不得中断进行中的任务。
   - `连接管理`、`自动中转` 等网络配置迁入「设置 → 连接与网络」；常规检查/管理类浮窗（设置、资源管理器、传输列表、设备详情）统一改为**非阻塞、可拖拽标题栏移动的多浮窗**（带轻量半透明/模糊、清晰层级）。仅目录选择器、OAuth 授权、删除/覆盖/卸载确认保留强焦点模态。
6. **跨节点小版本兼容与优雅降级**：稳定基线建立后，跨节点（如 `0.5.x` 与 `0.5.y`）通讯不得因微小版本差异整条链路崩溃；接口缺省字段或未升级能力须优雅降级并给出清晰、分级正确的状态提示（`success` / `info` / `warning` / `error` 显式区分，禁止以文案关键词猜测颜色或冷启动鉴权未就绪时闪红错）。

## 二、UI / UX 设计十三条刚性守则（跨组件统一执行）

### 1. 双基准线对齐（Two-Rail Alignment）
- 对齐不是像素平均，而是**左文字轨道 + 右动作轨道**。
- 所有面板标题、表单行标签、卡片标题严格对齐**左侧共享文字起始线**；所有开关、下拉、操作按钮与数字角标严格对齐**右侧共享动作终点线**。

### 2. 光学对称（Optical Alignment）
- SVG 图标（尤其三角播放、箭头、斜线、不规则几何体）须围绕**视觉重心**做光学微调，必要时在对称容器内偏移 `1px–2px`，避免几何居中但视觉偏左/偏右；容器内的文字/图标须有稳定呼吸留白。

### 3. 固定节奏（Spacing Scale）
- 所有间距统一锁定为 `4px` 倍数阶梯：`4 / 8 / 12 / 16 / 24 / 32px`：
  - 内联元素微距：`4px`（图标与短标签）
  - 同组控件/卡片内边距：`8px / 12px`
  - 独立区块/面板外边距：`16px / 24px`
  - 大结构隔离区：`32px`
- 禁止随意编写 `7px`、`10px`、`13px`、`18px` 等无序像素值。

### 4. 三级圆角梯度（Radius Scale）
- 严禁所有层级共用同一圆角，全站锁定 3 档 Token（内层圆角须始终小于外层，保证同心视觉）：
  - 小控件（按钮、输入框、标签、开关槽）：`6px`
  - 卡片、列表项、悬浮面板内框：`10px`
  - 大窗体、浮窗外壳、主容器：`16px`

### 5. 克制的色彩文法（Neutral + 1 Accent）
- 默认采用**「中性灰阶（Neutral Grayscale）+ 1 个主强调色（Accent）」**建立层次；功能提示色仅用于语义状态（成功/警告/错误/在线），不作装饰涂抹。
- 严禁使用「紫蓝渐变 + 模糊发光阴影（Glow）+ 无意义彩色圆点/角标」作为主背景或登录壳装饰。

### 6. 暗色表面层次与 WCAG AA 对比度
- 暗色主题严禁使用 `#000000` 纯黑大面积铺底，采用 **3 阶物理深度阶梯**：
  - 主背景 Canvas：`#121418`
  - 卡片/侧栏 Surface：`#1B1E24`
  - 浮层/悬浮窗 Elevated：`#252931`
- 所有正文字号文本颜色固定低刺眼高对比方案（如主文本 `#E6E8EC`，相对 `#1B1E24` 约 `15.03:1`），所有文本与核心图标在浅色/暗色双模式下必须满足 **WCAG AA `≥ 4.5:1`**（例如修复浅色模式下绿色在线文案对比度不足的问题，状态文本须独立使用深色高对比 Token，禁止直接复用指示灯浅绿）。

### 7. 五步「液态玻璃」浮层协议（Liquid Glass Popovers）
- 仅适用于菜单、快捷浮窗、顶部悬浮工具栏与次级气泡，不滥用于底层大背景：
  1. 真实背景模糊：`backdrop-filter: blur(14px–20px)` + `saturate(150%+)`；
  2. 多层混合阴影（环境柔影 + 近距离接触影）提供悬浮海拔；
  3. 仅在顶边/亮面施加极薄内部高光线条（`inset 0 1px 0 rgba(255,255,255,0.12)`）；
  4. 微弱半透明外描边（`1px solid` 主题边界色）；
  5. 内部前景字体不透明高对比，确保阅读零干扰。

### 8. Apple HIG 三大交互支柱
- **清晰（Clarity）**：信息层级一眼可辨，去冗余文案，状态/错误明确但不惊扰。
- **谦逊（Deference）**：UI 退居内容之后（网络画布、终端、对话、文件本身是主角）；Network 画布仅保留直接操作（拖节点移动、拖端口连线、点选边在悬浮条/上下文/键盘断开、右键检查而不强行切全局活跃设备，去掉冗余图例/筛选角标）。
- **深度（Depth）**：通过表面阶梯、浮窗层级和克制过渡传达上下级关系。

### 9. 侧边栏与主字体规范
- 侧边栏一级菜单统一左对齐、左侧带一致图标栏，核心字体与行高保持清晰可读（建议侧边栏主导航与分组标题遵循清晰可读字号层级与 `12px` 垂直节奏），底部配置/账户入口固定落底对齐。
- 主标题、次级标题、正文与等宽数据（路径、Hash、端口、版本号）必须使用明确的字体栈与 `tabular-nums` 等宽数字，消除数字跳动。

### 10. 控件选型矩阵（零原生丑控件）
- **严禁**在正式界面直接裸露未美化的浏览器原生 `<select>` 和原生 `<input type="checkbox">`。
- 严格按场景选型：
  - `2–4` 个互斥选项 → **分段控制器（Segmented Control）**
  - 即时生效的二值开关 → **Switch 切换开关**
  - 表单多选确认项 → **自定义样式复选框 / 标签多选**
  - 连续数值区间 → **Slider 滑块 + 实时数值显示**
  - 多于 5 项或远程搜索选项 → **自定义 Styled Select / Command Popover**

### 11. 设置页面信息架构（8 大分组与破坏性操作隔离）
- 设置界面统一按**「单一功能 + 明确作用域标签（本机 / 目标设备 / 私网 / 账号）」**组织为 8 个分类：**常规与外观、工作区与智能体、连接与网络、权限与共享、设备与 DSH、更新、账号、关于**。
- 分组之间用 `32px` 结构留白或极浅分隔区分；高危破坏性操作（卸载客户端、撤销信任、清除设备身份）必须从主配置流中视觉隔离至独立危险区（Danger Zone），并带二次确认。

### 12. 物理优先的可打断微交互（Physics-First Motion）
- 拒绝僵硬定长动画；所有展开、拖拽、切换须采用自然缓动/弹簧物理感（`cubic-bezier(0.22, 1, 0.36, 1)` 或弹簧曲线）且**必须可随时打断反向**。
- 侧边栏切换（含主栏与 Codeg/智能体视图转换）采用 `150ms–250ms` 轻量滑入 + 交叉淡入（`transform` + `opacity` 合成层动画）；退出动画比进入更轻、更快，严禁使用大位移缩放或阻断点击的遮罩动画。

### 13. 预测三角区容错（Safe Triangle for Cascading Menus）
- 所有多级上下文菜单、工作区/文件树级联右键菜单（含 Codeg 文件树菜单与资源管理器右键菜单）必须实现指针移动预测锥（Safe Triangle / 合理 Hover Intent 延迟），避免用户鼠标斜向移入子菜单时意外关闭父菜单。

## 三、Design Tokens 参考基准（CSS 变量落地标准）

```css
:root {
  /* 间距与圆角 */
  --space-1: 4px; --space-2: 8px; --space-3: 12px;
  --space-4: 16px; --space-6: 24px; --space-8: 32px;
  --radius-sm: 6px; --radius-md: 10px; --radius-lg: 16px;

  /* 动效 */
  --ease-physics: cubic-bezier(0.22, 1, 0.36, 1);
  --duration-fast: 150ms; --duration-normal: 220ms;
}

/* 暗色主题 3 阶物理深度 */
[data-theme="dark"] {
  --bg-canvas: #121418;
  --bg-surface: #1B1E24;
  --bg-elevated: #252931;
  --text-primary: #E6E8EC;   /* >= 15:1 on #1B1E24 */
  --text-secondary: #9CA3AF; /* >= 4.5:1 AA */
  --border-subtle: rgba(255, 255, 255, 0.08);
  --glass-highlight: inset 0 1px 0 rgba(255, 255, 255, 0.12);
}
```
