# DSH 原生 UI 复用桥

## 用途

此包在 Tether 文件与对话视图中复用 DeepSeek Harness 的原生展示组件。Tether 仍负责远端数据请求、设备隔离、树状态和事件适配；原生组件负责对应行、工具过程、Markdown 与图标的呈现。页面与会话能力边界见 [native-surface.md](native-surface.md)。

## 来源与许可

桥包从本机安装的 DeepSeek Harness 0.2.1-rc.2 bundle 提取并适配原 factory 词法作用域。桥包生成文件记录源 bundle 的 SHA-256；复用的上游代码按 MIT 许可分发，并在包内保留归属及许可证信息。生成器不会执行源字符串或注册上游 module ID。

## 复用范围

- 对话：Markdown、用户内容、思考行、轮次过程、运行状态及工具卡片。
- 工作区与会话：项目行、会话行及对应的简化交互适配。
- 文件：原生文件条目行、文件类型图标和 Markdown 展示；远端递归树与请求仍由 Tether 管理。
- 本地化：与选定上游 bundle 版本对应的中文词条。

更换上游版本时，应重新生成桥包并核对版本、SHA-256、许可证与归属信息。安装目标 DSH 环境后仍需进行实际加载验证；静态检查不能替代宿主渲染验收。
