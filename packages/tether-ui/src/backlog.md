# Tether UI 源码变更记录
- 2026-10-29：文件资源管理器顶栏加入前进/后退历史栈与上级；列头可切换名称/修改日期/大小排序（目录恒在前）；工具栏搜索框过滤当前目录（不区分大小写、可清除、无结果空态），Alt+←/→/↑ 导航；排序偏好经 localStorage 保留。
- 2026-10-28：刷新图标增加明确尺寸/唯一旋转动画；更新中心强刷等待所有检查结束再关闭 busy，错误 toast 4 秒自动收敛，更新入口固定“更新”并以圆点传达状态。
- 2026-10-28：本机 DSH 插件更新后出现“立即生效 / 稍后”确认；确认经 owner 插件管理器在线重载 surface 并核对运行版本；profile 不支持在线重载时明确提示重启要求，不触碰远端设备的 DSH 生命周期。
- 2026-10-28：新建文件请求显式 `overwrite:false` 并固定弹窗打开时的 device_id；设备切换后拒绝旧目录请求，避免清空既有文件或误刷新新设备视图。
- 2026-10-28：FilesPane 工具栏增加“新建文件”按钮，写入继续通过当前目标设备 `/fs/write` 并服从该设备的文件策略。
- 2026-10-28：远端设备更新顺序调整为 Node→已安装插件→APP；APP 远端检查/应用走设备 API，并在重启后等待 `app_version` 与更新状态追平。新增组件顺序 UI 回归。
- 2026-10-28：同一设备工作区重试失败时保留上次有效列表和选择；设备切换时清理旧目标工作区，legacy fallback 仅在目标尚无工作区数据时建立。
- 2026-10-28：工作区响应验证 `workspaces` 列表；异常在工具栏提供局部提示与重试，不再导致 React 白屏。Web 启动入口增加渲染错误边界和重试入口。
- 2026-10-27：移除已废弃的 APP 专属 `app-services.js` 占位组件；APP 连接入口只由共享 `app.js` 挂载。
- 2026-10-27：APP 与 DSH 共用同一“连接”入口及服务器连接面板；展示实际 API base 的地址、连接状态、最近检测与耗时，并支持重新检测。DSH 显式 Hub 时按 Hub 探测；业务 API 回退到 APP 代理后显示 APP 实际服务目标。Hub 编辑移入现有设置抽屉，不进入共享面板。
- 2026-10-27：共享 DSH 面板删除本机/目标节点及设备计数重复项，显示脱敏 Hub 地址和 `/api/state` 客户端请求耗时；失败后清空旧成功结果，URL userinfo/query/hash 禁止保存。
- 2026-10-27：DSH 状态 probe 区分 HTTP 401/403 的凭据/权限错误与不可达/超时；服务响应耗时 title 明确为客户端到服务接口的请求时间。
- 2026-10-27：无 Hub 配置时地址编辑框保持空值并显示 placeholder，摘要显示“未配置”、断开按钮禁用；旧配置含 userinfo/query/hash 时不显示秘密内容、不静默改写，提示用户重新输入安全地址。

- 2026-10-27：本机身份每 4 秒同步，状态失效时清除；非手动选择时自动切换到本机 Node，手动选中节点保持不变。

- 2026-10-27：APP、DSH 本机插件及当前在线选中节点每 6 小时检查一次更新；标题栏显示新版本或检查失败提醒，检查按组件、设备与选择 epoch 隔离并合并并发请求，不触发安装。

- 2026-10-27：修正一键更新阶段失败处理；各宿主返回 ok:false 会进入错误态，序列失败立即停止，authority 始终取自本次检查结果并原样传递。

- 2026-10-27：更新中心加入单组件一键更新，串行执行检查、下载校验、安装；设备目标变更时中止后续步骤，目标设备安装继续固定检查得到的 authority，并保留原有独立操作入口。

- 2026-10-27：API 请求在每个候选 base 上单独获取宿主请求头，避免 Hub 凭据随本机回退请求发送。
- 2026-10-27：移除旧版 `version.json`/`git pull` 提示，改为可手动打开的更新中心；APP 自更新走受信任 IPC，Node/插件更新只对明确选中的设备调用 Controller API，并显示目标身份、版本、离线/旧协议/忙碌状态和重试入口。
- 2026-10-27：DSH 更新中心新增当前插件本机卡片，通过插件实例 RPC 更新自身；另保留明确标注的选中目标设备插件卡片，二者互不混淆。
- 2026-10-27：目标设备更新状态按 deviceId 与选择 epoch 隔离；切换设备清除旧准备包与错误，迟到响应不能覆盖当前设备状态。
- 2026-10-27：目标设备更新在状态/检查时固定当前 API authority，prepare/apply复用同一Hub或Controller地址；更新请求失败不会跨控制面回退。
- 2026-10-28：从 DSH 插件 bundle 的版本常量种子显示本机运行版本，不依赖更新 RPC 或网络检查成功后才显示。
- 2026-10-28：更新中心并行读取状态与版本检查；状态先显示，最新版本结果缓存 5 分钟，手动刷新强制检查，单请求 6.5 秒超时后明确显示失败。
# 变更记录

- 2026-10-28：DSH 本机插件卡片区分运行版本与磁盘版本；更新包尚未由 DSH 重启加载时显示重启提示，不显示“已是最新”。
- 2026-10-28：`NativeSurface` 增加自动重连（DSH boot 失败或瞬态 surface 错误，退避 1/2/4s、最多 3 次，耗尽后回到 Tether 错误页）；宿主 boot 对 502 不重试，控制链抖一下就永久停在失败页。
- 2026-10-28：代码页首开竞态——预取请求本身直接交给 `openPreview`（原先把 `then` 的返回值当数据，必为 `undefined`），失败或无效预取回退 `postRetry` 且不写缓存；同次改动加标签栏、逐行当前行高亮与可拖动分隔条，暗色配色走 `data-ds-dark-theme`。
- 2026-10-29：CSV/TSV 预览默认用只读表格（RFC4180 引号/逗号/字段内换行、BOM/CRLF、5000 行/100 列上限并在底栏提示），标签栏分段按钮切回纯文本；XLSX 复用节点首个工作表 TSV 输出，不新增解析依赖。
- 2026-10-29：本机 DSH 工作区改走节点回环 surface：`isSafeNativeSurfaceUrl` 接受 `http://127.0.0.1:<port>/?token=`，同机 token URL 跳过“Hub 指向 loopback 网关”防护；更新中心版本行固定为 `APP|插件 X(Y)/Node X(Y)`（各组件用各自 latest），删除随检查状态漂移的“当前/· 最新/待生效”文案。
- 2026-10-29：插件端 surface 优先走宿主给的快路径（`host.surfaceBase(isLocal)`，DSH host → 18892，失败回退 Hub），NativeSurface 从面板拿到 `localDeviceId`；轮询对同机 token URL 比较 token，DSH 同端口重启也能换新地址。
