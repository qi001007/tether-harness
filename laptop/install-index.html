TTetherv0.3.6

下载 Tether

把另一台电脑变成可远程操作的资源管理器、终端和工作区。Windows 直接下载；Linux / macOS 一条命令装成系统服务。

Windows

Tether APP解压后运行 tether-app，约 38 MB（含 Electron 运行时与三平台 croc） DSH 插件给 DeepSeek Harness 安装的面板插件，约 1.4 MB Tether Node只装被控端，不装界面，约 36 MB（含三平台 croc）

Linux / macOS 一键安装

curl -fsSL https://8-220-198-26.sslip.io/install.sh | sudo bash

运行后会提示登录一次 Tether 账号，脚本自动下载最新 Node、装成系统服务并注册设备；登录令牌只用于首次注册，随后会从配置里删除。需要 root 权限，安装后可用 systemctl status tether-node 查看。

手动下载 Node

如果不想用一键脚本，可下载上面的 Node ZIP，解压后运行 bash laptop/install-node.sh --controller wss://8-220-198-26.sslip.io/ws/node。这是开发者方式，普通用户建议用一键安装。
